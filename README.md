# PUBLIC DOOM `P(●)` — Interactive 3D Low-Poly PS1 World

Interactive 3D website and merchandise archive for the **PUBLIC DOOM** YouTube channel featuring **Jax**, **Topeng**, **Ayesha**, and **Athena**.

## Features
- **PS1 Low-Poly + Ordered 4×4 Bayer Dithering Engine**: Custom WebGL2 / Three.js pipeline with vertex snapping, affine texture mapping, ordered Bayer dithering, 4-color Obra-Dinn palettes, halftone toon shading, and Trinitron CRT barrel curvature & scanlines.
- **4 Interactive Characters**:
  - **Jax** — Main Host / Writer / Homer's Diner Shift Lead
  - **Topeng** — Co-Host / Research Labs / Anonymity Lead
  - **Ayesha** — Creative Director / Visual Essayist
  - **Athena** — Synth Composer / Lore Archivist
- **5 Exploreable Low-Poly Worlds**:
  1. **The Studio (`WORLD 01`)** — Public Doom HQ Broadcast & Editing Bunker
  2. **The Playground (`WORLD 02`)** — After-Hours Concrete Park & `"TIDAK MAU"` Wall
  3. **Homer's 24H Diner (`WORLD 03`)** — Their Favorite Restaurant (*Est. 8th Century BC*)
  4. **The Grass Field (`WORLD 04`)** — Sunlit Voxel Meadow & Bus Stop Shelter
  5. **3D Atlas Map (`WORLD 00`)** — Spatial Diorama Hub Connecting All Sectors
- **Official Merchandise Archive**: Interactive store with pixel-dithered previews, live **Try On in 3D** character outfit swapping, and printable thermal receipt checkout.
- **Original Soundtrack**: Background music and stems from *DEATH OF INTERESTING THINGS*.
